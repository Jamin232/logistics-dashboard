时效趋势（平均全程时效 / 时效达标率）

平均时效 = 已完成签收票（签收日 − 出货日）均值；达标率 = 已完成票中「是否达标=是」占比。

异常 / 未达标率趋势

异常率 = 含延误 / 赔付索赔开查 / 超时 的票占比；未达标率 = 已完成签收票中「是否达标=否」占比，与达标率互补相加为 100%。
